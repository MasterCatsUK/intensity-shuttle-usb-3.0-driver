# Shuttle Camera 0.1.39 - GitHub update

This update brings the published source and documentation forward from 0.1.31 to the installed0.1.39 software. The installer binary is the existing checked0.1.39 package; this documentation refresh does not rebuild it or change the running Mac.

## Added since the earlier repository version

- Grouped Capture/Picture/Video Output/Idle Screen panels.
- Live input brightness, contrast, colour/saturation and horizontal sharpness.
- Capture-resolution readback retention during reconnects and safer driver-readiness controls.
- Configurable editor idle delay with pictures, bars, black, hold and silent looping movies.
- Fit, Fill and Stretch for media/desktop output; Stretch follows live desktop resolution changes.
- HDMI/S-Video/composite/component format selection and SD/HD media scaling.
- Existing-screen mirroring and an experimental extended desktop; PAL/NTSC desktops now appear in macOS Displays.
- Clearer Use Shuttle Audio wording; audio device identifiers remain compatible.

The user confirmed PAL/NTSC extended displays appear and work and later reported playback working. Live software tests checked all eleven requested desktop resolutions into HD/PAL/NTSC surfaces. PAL composite bars playback finished with zero USB packet/transfer errors. These observations do not certify all codecs, all 4K projects or every analogue mode.

Camera17, output12, HAL3 and Premiere transmitter1 remain the bundled driver versions. Host39 and desktop sender include the latest scaling behaviour. See individual Whats-New notes for technical history. Source, illustrated guide, checksums and the original icon are included; no Adobe SDK or personal recordings are redistributed.

Experimental signing/SIP requirements are unchanged. Read the guide before installing. This upload bundle was prepared locally; it has not been pushed to GitHub automatically.
