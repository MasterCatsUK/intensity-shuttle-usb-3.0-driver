# Credits and acknowledgements

Shuttle Video, Shuttle Player and the macOS driver build on the work of many other developers. Thank you to the authors and maintainers below for making the foundations, tools and documentation available.

This is an independent community project maintained by **Andrew / [MasterCatsUK](https://github.com/MasterCatsUK)**, developed with AI assistance and tested on his Mac Studio and Intensity Shuttle USB 3.0. It is not a driver written entirely from scratch: **Steinar H. Gunderson's bmusb USB capture implementation is a key foundation**, ported and extended for this project.

These acknowledgements describe dependencies, references and inspiration separately. They do not imply that upstream authors worked on, tested or endorsed this macOS project. Full copyright and licence notices take precedence over these summaries; see [third-party notices](THIRD-PARTY-NOTICES.md).

## Platform documentation and implementation references

- **Apple** — macOS, Xcode/Clang, AppKit, AVFoundation, Core Media I/O, Core Audio, Core Image, VideoToolbox, ScreenCaptureKit and associated SDK documentation provide the native application, capture, recording, display and audio interfaces. Useful references include [Creating a camera extension with Core Media I/O](https://developer.apple.com/documentation/coremediaio/creating-a-camera-extension-with-core-media-i-o) and [Building an Audio Server Plug-in and Driver Extension](https://developer.apple.com/documentation/coreaudio/building-an-audio-server-plug-in-and-driver-extension). libASPL's Apple-derived portions retain their original Apple notices. Apple's SDKs and frameworks are obtained separately under Apple's terms.
- **Adobe** — the [Premiere Pro C++ SDK and documentation](https://developer.adobe.com/premiere-pro/) supplied the Mercury Transmit interface contracts used to build the Premiere output adapter. The SDK must be obtained separately under Adobe's terms; its headers and sample implementation are not redistributed in this repository.
- **The Syphon project / Syphon-Transmit authors** — [Syphon-Transmit](https://github.com/Syphon/Syphon-Transmit) was an implementation reference when researching Adobe Mercury Transmit. See the recorded [Premiere integration references](unified/premiere/IMPLEMENTATION.md#sources). This repository does not bundle the Syphon framework or its transmitter implementation.
- **The Chromium Authors** — their [macOS virtual-display utility](https://chromium.googlesource.com/chromium/src/+/HEAD/ui/display/mac/test/virtual_display_util_mac.mm) documented CoreGraphics virtual-display interface facts used to research the experimental extended desktop. [ShuttleDisplay](unified/src/output/VirtualDisplayMain.mm) is an original runtime wrapper; no Chromium implementation is bundled. Chromium's source has its own BSD-style terms. This undocumented macOS interface may change.
- **Blackmagic Design** — creator of the Intensity Shuttle hardware. Its [Desktop Video manual](https://documents.blackmagicdesign.com/UserManuals/DesktopVideoManual.pdf) was a hardware/setup reference. The proprietary Desktop Video driver and firmware are not included as project source. Device and company names identify compatibility, not endorsement.

## Development and documentation tools

The build and packaging scripts use **Apple Xcode Command Line Tools** (including Clang, `xcrun`, `lipo`, `codesign` and installer tools), **GNU Make** and **Python**. The illustrated-guide generator uses **[ReportLab](https://www.reportlab.com/)** and **[Pillow](https://python-pillow.org/)**. **Git** and **GitHub** support source control and distribution. These tools are acknowledged for development/documentation use; this does not mean each is bundled in the installed apps. libASPL's retained source also credits **[Jinja](https://jinja.palletsprojects.com/)** for its upstream code generators.
