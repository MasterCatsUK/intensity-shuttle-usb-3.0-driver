# Shuttle Video 0.1.54

The bundled logo movie plays once on an idle Shuttle when the app opens, then holds the final picture silently. Any app control/menu action releases the startup sender before continuing. Disable it under Idle Settings → Play startup video on Shuttle. Saved output format and connection are used, with Stretch. It does not stop another app’s capture/output or change the Mac sound route.

Mac screen and Shuttle output independently select Video / Video scopes / Off for Final Cut and Premiere. With Mac on select Virtual Shuttle in Final Cut; Shuttle-only uses Intensity Shuttle — HDMI Output. Premiere uses its existing Intensity Shuttle — HDMI Output Mercury Transmit plug-in. Route editor sound through Virtual Shuttle Audio.

Before installation, disable editor output, stop recording/capture/output and quit camera/editor/Shuttle apps. Enter the administrator password directly in macOS. Camera21/output13/audio4/Premiere2 are unchanged; enabled drivers need no reactivation. Shuttle Player0.1.1 is included separately in the complete ZIP; copy it to Applications.

Experimental unsigned installer/ad-hoc components, no notarization. Existing SIP-disabled development requirements remain. The installer does not alter security. Universal macOS14.4+ main app; Intel/older macOS runtime and fresh-machine installation untested. Offline tests pass; live startup/routing checks remain pending. See docs/Whats-New-0.1.54.md and the security preparation/removal guide in the included source.
